# Restaurant-Order-Tracker

## Demo Video
Watch a short demo of the app in action: [Demo Video[(https://youtu.be/V1rdqi5Get4)]]

## Overview
Restaurant Order Tracker is an Android application that allows customers to track their takeaway orders and staff to manage order status.  
The app supports multiple restaurants and provides functionality for order tracking, ratings, and status updates.

## Features
### Staff
- Add new orders (records customer, staff member, and order time)
- Update order status: Pending → Ready → Collected
- View average ratings for their orders

### Customers
- Track status of all orders by restaurant
- Rate service with thumbs up/down
- View average rating for each restaurant

### General
- User authentication (login/register)
- Real-time data updates between app and backend
- Multi-screen Android interface with intuitive design

## Technologies Used
- **Frontend:** Android (Java, XML layouts)
- **Backend:** PHP, MySQL
- **Tools:** Android Studio, GitHub
